# 딩동 기능 명세 초안

> APK 정적 분석에서 식별된 경로와 문자열에 근거한 초안이다. 실제 실행 전까지 추정 기능은 확정 명세로 취급하지 않는다.

## 제품 목표
학교 시간표·급식·학급 운영 정보를 학생과 교사가 확인하고, 일정 변경 및 소통을 지원하는 Flutter 앱.

## 기능 영역
| 영역 | 기능 | 우선순위 | 상태 |
|---|---|---:|---|
| 계정 | 로그인/로그아웃 | P0 | 설계 |
| 온보딩 | 학교·학년·반·역할 설정 | P0 | 설계 |
| 홈 | 오늘 수업 및 주요 일정 | P0 | 설계 |
| 시간표 | 주간/개인/학급 시간표 | P0 | 설계 |
| 교시 | 교시 시간 설정/조회 | P1 | 설계 |
| 급식 | 날짜별 급식 | P0 | 설계 |
| 과제 | 과제 목록/상세 | P1 | 설계 |
| 변경 | 수업 변경 요청 | P1 | 설계 |
| 요청 | 요청 목록/처리 | P1 | 설계 |
| 채팅 | 사용자 간 메시지 | P2 | 설계 |
| 위젯 | 오늘 시간표/일정 | P0 | 설계 |
| 광고 | 광고 슬롯 | P2 | APK 포함 흔적, 동작 미검증 |

## 역할
- 학생: 개인 시간표, 급식, 과제, 변경 요청, 채팅
- 교사/학급 운영자: 학급 시간표, 교시 설정, 과제·요청·대체/보강 관리

역할별 권한은 실제 DB 스키마와 RLS 정책 확인 후 확정한다.

## 동기화 원칙
- NEIS 원천 데이터와 Supabase 사용자/학급 데이터를 출처별로 분리한다.
- 시간표는 주기적으로 재조회하고 최신 응답을 반영한다.
- NEIS에 아직 입력되지 않은 변경은 앱이 미리 알 수 없다.
- API 실패 시 기존 캐시를 보존하고 마지막 성공 동기화 시각을 표시한다.
- Android 위젯 갱신은 OS 백그라운드 제한에 따라 지연될 수 있다.

## 수용 기준
- 학교/학급 설정을 저장하고 재실행 후 복원한다.
- 날짜별 시간표와 급식을 조회한다.
- NEIS 변경 내용이 다음 동기화에 반영된다.
- 네트워크 오류와 빈 응답을 구분한다.
- 위젯에 날짜와 마지막 갱신 시각을 표시한다.
- 학생/교사 권한을 서버 RLS로 검증한다.
